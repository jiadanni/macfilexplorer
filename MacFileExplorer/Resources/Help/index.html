Getting Started

Welcome to MacFileExplorer, a powerful and modern file manager for macOS. This guide will help you get the most out of the application.

First Launch

When you first launch MacFileExplorer, you'll see the Start screen with helpful widgets to get you oriented. From here you can:

  • Access your favorite locations quickly
  • View storage overview
  • See quick actions
  • Browse recent files
Tip: MacFileExplorer may request permissions to access certain folders on your Mac. Grant these permissions to enable full functionality.

Navigation

Basic Navigation

  • Back/Forward: Use ⌘[ and ⌘] to navigate through your browsing history
  • Parent Folder: Double-click the folder icon in the toolbar or use the breadcrumb navigation
  • Quick Navigation: Use the sidebar to jump to common locations

Go Menu Locations

The Go menu provides quick access to important system locations:

  • ⌘⇧H - Home folder
  • ⌘⇧D - Desktop
  • ⌘⇧O - Documents
  • ⌘⇧L - Downloads
  • ⌘⇧A - Applications
  • ⌘⇧U - Utilities
  • ⌘⇧I - iCloud Drive
  • ⌘⇧R - AirDrop

Connect to Server

Access network locations using ⌘K. Supports SMB, AFP, and other network protocols.

View Modes

MacFileExplorer offers multiple view modes to suit your workflow:

List View (⌘1)

Traditional file list with sortable columns showing name, size, date, and kind.

Icon View (⌘3)

Visual grid layout with file thumbnails and previews.

Column View (⌘4)

Multi-column browser for hierarchical navigation.

Windows List (⌘5)

Compact list optimized for file management tasks.

Preview Pane

Toggle the preview pane with ⌘P to see file contents without opening them. The preview pane supports:

  • Images (PNG, JPEG, GIF, etc.)
  • PDFs and documents
  • Videos and audio files
  • Code and text files with syntax highlighting

Split View

Create split panes to work with multiple folders simultaneously:

  • Split Vertically: View → Split Vertically
  • Split Horizontally: View → Split Horizontally

Each pane has its own status bar showing selection and folder information.

Features

Tabbed Browsing

Work with multiple folders in tabs, just like a web browser. Create new tabs with ⌘T and switch between them easily.

Storage Analyzer

Analyze disk usage and find large files:

  • Visual breakdown by file categories
  • Sort files by size
  • Navigate to largest folders
  • Quick cleanup suggestions

Integrated Terminal

Toggle an integrated terminal with ` key. The terminal automatically follows the current folder location.

Hidden Files

Toggle visibility of hidden files and system files with ⌘⇧. to access configuration files and system folders.

Favorites & Quick Access

Pin frequently used folders to the sidebar for instant access. Add folders by dragging them to the Favorites section.

File Operations

  • Copy/Move: Use standard shortcuts or drag and drop
  • Duplicate: Right-click and select Duplicate
  • Rename: Select a file and press Enter
  • Delete: Move files to Trash with ⌘Delete

Settings

Access settings with ⌘,. Customize MacFileExplorer to your preferences:

General Settings

  • Default view mode
  • Show/hide hidden files by default
  • Open settings in tab vs. window

Appearance

  • Theme selection
  • Font and icon size
  • Toolbar customization

Go Menu Customization

Choose which locations appear in the Go menu and assign custom shortcuts to your most-used folders.

Permissions

Manage folder access permissions and security-scoped bookmarks for restricted system locations.

Troubleshooting

Permission Issues

Problem: Cannot access certain folders or see "Permission Denied" errors.

Solution:

  1. Go to System Preferences → Security & Privacy → Privacy
  2. Select "Files and Folders"
  3. Grant MacFileExplorer access to the required locations
  4. Restart the application

Preview Not Working

Problem: Files not showing preview in preview pane.

Solution:

  • Ensure the file type is supported
  • Try toggling the preview pane off and on
  • Check file permissions

Slow Performance

Problem: Application feels sluggish when browsing folders with many files.

Solution:

  • Switch to List view for better performance with large folders
  • Disable preview pane for folders with thousands of files
  • Close unused tabs

Network Shares

Problem: Cannot connect to network shares.

Solution:

  • Verify the server address format (e.g., smb://server.local/share)
  • Check network connectivity
  • Ensure you have correct credentials
  • Try mounting the share in Finder first
Still having issues? Check the system console for error messages or visit our support resources.
